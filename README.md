# 調と和音のれんしゅう

調号と和音を覚えるための練習アプリです。ブラウザで動き、スマホでもPCでも使えます。

**アプリを開く → https://nakaki84n.github.io/tonart-trainer/**

## 練習モード

| モード | 出題 | 答え方 |
|---|---|---|
| ① 調号 → 調 | 五線譜の調号（♯・♭） | 調名を入力（例：`A-Dur`、`fis-moll`） |
| ② 調 → 調号 | 調名 | ♯／♭／なし と、付く音を選ぶ |
| ③ コード → 構成音 | コード名 | 画面の鍵盤で構成音をタップ |
| ④ 構成音 → コード | 五線譜の和音 | コード名を入力 |

- 1回10問で、終わると点数とまちがえた問題が表示されます。
- まちがえた問題は、次回から多めに出題されます。
- ③④では、正解すると和音が鳴ります。

## 出題範囲

- **調**：♯0〜7個、♭0〜7個の調号すべて（長調15、短調15の計30調）
- **和音**：12の根音の長三和音と短三和音（計24個）

## 表記

ドイツ式の音名を使います。

- H ＝ シ、B ＝ シ♭
- ♯ は `-is`（Fis、Cis）、♭ は `-es`（Des、Ges）。ただし Es、As、B は例外
- 長調は大文字で `D-Dur`、短調は小文字で `d-moll`

入力では大文字・小文字やハイフンの有無は区別しません（`fis moll`、`FISMOLL` も正解）。

## 設定

- **付く順番もチェックする**：オンにすると、②で♯・♭が付く順番どおり（Fis → Cis → Gis …）にタップしないと正解になりません。
- **音 オン／オフ**：画面右上のボタンで切り替えます。

## 記録について

正答率などの記録は、使っている端末のブラウザの中だけに保存されます。外部には送信されません。スマホとPCでは記録が別々になります。

## 自分のPCで動かす

`index.html` をダウンロードして、ブラウザで開くだけで動きます。インストールやサーバーは不要です。
